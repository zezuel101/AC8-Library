Not all assets were included for sake of storage along with most people just wanting the models for the airplanes and whatnot, the download file is [here](https://drive.google.com/file/d/1GYCPktUsgujpd5VEn5f_BAx7uLR_G1Sp/view?usp=sharing)
> [!IMPORTANT]
> There will probably be issues with some textures and .glb models with how Project Aces handled them or maybe the software I used to extract it out of the game (UE4SS for the .usmap, AESDumpster for the AES Encryption key and also FModel for viewing inside the .paks/.utocs).
> If you are going to do this by yourself which I highly recommend instead of grabbing stuff from here, please make sure to get the blender .PSK import/export extension to properly import meshes from FModel over to Blender without corruption. I recommend people to do the extracting, ripping, etc by themselves because there is a fuller and richer experience by yourself and whatnot, this is also why I am working on a recompilation of Ace Combat 5: The Unsung War as this library of assets directly from the games does not seem to help others it seems.
